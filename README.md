# XO Data Co. Website

High-performance website for XO Data Co. focusing on data analytics, custom app development, and AI integration.

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Shadcn UI

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Deployment

Deploy to Vercel with:

```bash
npx vercel --prod
```
